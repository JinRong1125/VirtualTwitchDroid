# :core:designsystem

The Material 3 theme and the **design-token** layer — the only visual constants the app may use: Color,
Typography, Shape, Spacing, IconSize, Sizing, Elevation, Motion. Also the reusable Twitch-style UI kit
(badges, tag chips, streamer row, follow button, chat row, message input, emote grid, live overlay, network
image). Zero-dependency guard tests (`ThemeTokensTest`, `NoHardcodedFontSizeTest`) enforce token usage.
